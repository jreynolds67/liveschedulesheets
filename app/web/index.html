Sheet tabs & row mapping

Every visible tab is read (hidden tabs like COUNT are skipped). Pick a tab to preview it, and untick Include this tab to leave it out. Rows are detected automatically; check the highlighted rows and the Parses as line. If a row is wrong, choose the right one from the dropdowns, or click a row in the sheet. Your choices stick to that row even if rows are inserted above it. Click Save to apply.

PCR → channel mapping

Each PCR letter from the sheet records on every LSP channel whose name contains the match text as a whole word - e.g. “PCR A” matches “01 - PCR A PGM (x264)” and “02 - PCR A CLEAN (ProRes422)”, but not “PCR AB”. Channels are looked up live on every pass, so added or renamed channels are picked up automatically.
The Vantage workflow variable that gets the event's name from the sheet (e.g. “VB STANFORD PITT”) on every event the tool creates or updates. Leave blank to turn this off.

Scheduling

Replaces the default record length for events whose name contains the sport code as a whole word, ignoring case - e.g. “WSOC” matches “WSOC vs Texas”. The first matching row wins. Changing a length also updates events already in LSP that haven't started (unless they're locked).

Event fixes

Changes you made to single events in Preview: a PCR assigned when the sheet has none (or the wrong one), or an event set to ignore so it's never scheduled. They're applied on top of the sheet on every sync, matched by tab, date and event name. REMOVE one to go back to what the sheet says.
